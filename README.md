# Checkpoint 1 - Agente Base en n8n 

## Descripción Workflow de n8n que implementa un agente autónomo básico en modo Tools Agent utilizando Ollama como modelo local. 

## Componentes - Chat Trigger - AI Agent (Tools Agent) - Ollama Chat Model (llama3.1:8b) - Simple Memory - Google Sheets como Tool lateral - Gmail para observabilidad

## Objetivo Calificar leads comerciales y registrar automáticamente las oportunidades detectadas en Google Sheets.
